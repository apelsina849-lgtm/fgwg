# SHREKSICH AI — отдельный бот сообщества (MVP)

Этот каталог не меняет существующий магазин, ферму, баланс или торговую систему. Запускать **отдельным Railway service**, не заменять текущий Dockerfile и сервис магазина.

## Безопасный запуск

1. Через @BotFather отозвать ранее опубликованный токен и выпустить новый.
2. Создать отдельный Railway service из ветки `feature/shreksich-ai`.
3. Root directory: `/`; start command: `python shreksich_ai/community_bot.py`.
4. Добавить переменные:
   - `SHREKSICH_AI_BOT_TOKEN` — **только новый токен**.
   - `SHREKSICH_AI_ADMIN_IDS` — Telegram user ID администраторов через запятую.
   - `SHREKSICH_SHOP_URL` — URL магазина.
   - `SHREKSICH_AI_DB` — путь к SQLite на постоянном томе Railway.
   - необязательно `SHREKSICH_AI_API_URL`, `SHREKSICH_AI_API_KEY`, `SHREKSICH_AI_MODEL` — совместимый с Chat Completions API провайдер.
5. Добавить бота в чат. Для проверки обычных сообщений нужно отключить privacy mode у @BotFather. Для санкций понадобятся права администратора (в MVP бот лишь предупреждает, не удаляет сообщения).
6. Не запускать два экземпляра polling для одного токена.

## Реализовано в MVP

- `/ai` — ИИ при настроенном провайдере, без выдумывания сведений о магазине.
- `/quiz`, `/answer` — викторины без начисления валюты.
- `/trade`, `/trades` — объявления о поиске обмена, **без блокировки и передачи предметов**.
- `/guardstats` — статистика предупреждений для администраторов.
- Антифлуд и эвристические предупреждения о мошенничестве.
- `/shop` — ссылка на магазин.

## Что ещё нужно до production

- Подключить реальные API магазина с авторизацией и разграничением прав.
- Реализовать escrow/атомарные трейды внутри существующей базы данных.
- Подключить награды из призового фонда с идемпотентностью.
- Добавить полноценную модерацию с апелляциями и журналом.
- Перейти с SQLite на существующую БД проекта либо закрепить persistent volume.
- Написать тесты, настроить мониторинг, резервное копирование и rate limiting.

**Не используйте опубликованный в чате токен.** В репозитории его нет.
