# NIGHT PROTOCOL — WLzar Company

Portable Windows build.

1. Extract the ZIP to a normal writable folder (Desktop, Games, Downloads).
2. Run **NIGHT_PROTOCOL_Launcher.exe**.
3. The launcher verifies the game and can install future updates automatically.
4. Press **PLAY**.

## Controls
- 1 — Run diagnostic
- 2 — Authorize entry
- 3 — Deny entry
- ESC — Menu

The game includes 10 interface languages and saves settings in the Godot user data folder.

Build channel: alpha
Version: 0.1.0
