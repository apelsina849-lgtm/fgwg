NIGHT PROTOCOL — WLzar Company

READY PORTABLE WINDOWS BUILD
Version 0.1.0 alpha

HOW TO START
1. Extract the downloaded ZIP completely.
2. Open the "portable" folder.
3. Double-click NIGHT_PROTOCOL_Launcher.cmd.
4. Press PLAY.

No Godot editor, project import, Node.js or Python is required.
Windows 10/11 includes PowerShell. Microsoft Edge is used in app mode when available; otherwise the default browser opens the game.

UPDATES
The launcher checks the NIGHT PROTOCOL update manifest on GitHub. Future game updates can be installed with CHECK FOR UPDATE. REPAIR GAME FILES re-downloads the current release.

FEATURES
- WLzar Company loading screen
- MARA VOSS / Incident Terminal launcher preview
- Six-visitor decision shift
- Diagnostic / Authorize / Deny gameplay
- Persistent settings and shift save
- 10 interface languages
- CRT, film grain, screen shake, volume, high contrast and fullscreen controls
- Offline play after installation

Controls: 1 Diagnostic, 2 Authorize, 3 Deny, ESC Menu.
